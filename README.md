# PackPin — Web

Find Pokémon TCG vending machines near you, official and independent, worldwide, with community restock reports.

This is the **web** side of PackPin: a public repository holding the legal documents —
privacy policy, terms of use, support — served by GitHub Pages at `packpin.app`. It is a
submodule of the `graboosky/packpin` container.

What goes here and how it is published: `CLAUDE.md` in this folder.
